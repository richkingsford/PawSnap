# SheetPlan

SheetPlan is a browser-based ceiling drywall layout planner. Enter the ceiling dimensions, choose a sheet size and direction, and it generates a scaled placement plan, sheet count, waste estimate, and course-by-course cut list.

## Run

Open `index.html` in a browser. No build step or dependencies are required.

## Notes

The planner is intended to reduce field measuring and cutting mistakes. Verify framing, obstacles, access panels, and local material requirements on site before cutting.
