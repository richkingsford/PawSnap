02 · Set the reference

Mark four framing intersections forming a real rectangle on the same ceiling plane. Click A → B → C → D around its perimeter. Its dimensions can be unknown in board mode.

Then mark edge-to-edge width across one board and across another running in a different direction. Each marked width is assumed to be exactly 2 inches. Use the board face, not the gap or center-to-center spacing. Keep both on the selected plane.

A single ordinary photo has no absolute scale. A valid reference enables perspective-correct measurements, but accuracy still depends on corner placement, reference measurements, image resolution, lens distortion, and a flat surface. Off-plane beams, ducts and sloping sections need separate calibration. The sample photos alone cannot establish verified inch measurements.
